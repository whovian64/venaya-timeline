# Venaya Timeline

Fan-made timeline and lore reference for Andrew Rowe's Arcane Ascension universe. Spoilers for all 15 books.

## How entries work

The site is static. The Add entry form opens a prefilled GitHub issue; a workflow checks it and appends it to `entries.json`. The site reads that file, so new entries appear within a few minutes.

## Moderation

Comment on an entry's issue as the repo owner:

- `/remove` removes that entry.
- `/block` removes everything the issue author added and blocks them.

You can also edit `entries.json` directly.
